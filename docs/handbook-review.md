# Handbook review and live editing

Before authoring, follow [the handbook authoring standard](handbook-authoring-standard.md) and the matching template in `handbook-templates`. This standard controls page structure, native components, visual emphasis, translation, navigation and verification.

## Authoring workflow

The dedicated light guide instance contains a normal copy of the handbook resource pack. Minecraft rejected the previous symbolic link; that link is archived, not used. Other instances and worlds remain independent.

Set GuideME's official live-preview Java arguments in this instance's launcher settings, using guide-live-preview-java-arguments.txt. The source path points directly to the generated repository pages. Minecraft discovers the handbook from the installed normal resource pack; GuideME then reads and watches the repository source folder. No symbolic link, allowlist exception or repeated page copying is required.

The normal folder has been installed and checked. Launcher arguments still need Lucas to enter them because computer use is prohibited. The guide resource pack also needs re-enabling after Minecraft removed it from the selected list. Do not claim native watching is working until the next launch and a live page edit are checked.

Author gameplay articles in docs/handbook-content.json. Navigation, coverage tables and page files are generated by scripts/build-handbook-draft.py. Publisher descriptions are cached in docs/handbook-project-descriptions.json, with source links. Do not overwrite generated articles by hand.

## Accepted review

The home is Astropunk, not Activities. Catalogs describe installed mods and worlds; mechanics guides are supporting articles. Category catalogs contain topic contents and linked mod tables. Supporting libraries and administration remain accessible in the same catalog structure rather than an unrelated homepage appendix.

Player-facing prose describes the pack, not the authoring process. Remove review requests, prototype commentary and future interface promises. Keep an honest work-in-progress marker on unwritten articles.

Use native item slots for hover names and tooltips. Decorative ItemImage does not provide them. Use real crafting recipes when the released renderer supports them. Processing examples must use real recipe data and item models, never invented outputs or generated instructional artwork.

The initial ore-processing revision includes the actual Millstone crafting recipe and icon-based material comparisons for milling, crushing and washing. Native GuideME does not have Create recipe renderers in this instance; those processing comparisons use the checked Create recipe data instead of unsupported Recipe elements.

Use native links for catalogs and related handbook topics. Item links route to handbook pages through item associations, not automatically to the external recipe browser. Native item-browser and Ponder screen opening remain separate integrations.

Use the existing toolbar for history navigation. Remove duplicated, stacked return links. Add controls guidance with current KeyBind labels and clearly separated browser defaults. Avoid backticks around search examples because this release renders inline code in italics.

## Readability

GuideME has no independent font-size setting in its shipped configuration. The interface scale affects text and other screens. Bounded page width replaces full-screen paragraphs; concise sections and tables reduce scanning. Do not silently change a player's globally synchronized interface scale.

## Verification boundary

Source validation checks language parity, links, graph reachability, coverage, work-in-progress markers, native tags, identifiers and temporary wording. The compiled helper needs an in-game check after its first restart. Filesystem visibility does not prove the current game has reloaded the pages.

Publisher summaries are English source text. Chinese articles and navigation are translated, but the new exhaustive mod-description tables need a dedicated Chinese translation pass. Do not label those summaries as translated.
