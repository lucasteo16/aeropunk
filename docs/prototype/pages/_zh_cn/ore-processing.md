# 矿石加工

用机械动力的设备把原料加工成有用的产物。先看配方，再选工艺，不要以为机器越大就一定能获得更多金属。

## 从粗铁开始

粉碎粗铁可以得到粉碎铁矿石，并有概率得到经验颗粒。洗涤粉碎铁矿石可以得到铁粒，并有概率得到红石。决定建造什么之前，先比较游戏中的实际配方。

在物品浏览器中搜索 `@create`，再查找粉碎轮和鼓风机。英文检索词：Crushing Wheel, Encased Fan, Raw Iron。这个查询在中英文游戏语言下的表现还需要验证。

## 查看已有演示

粉碎轮的思索演示会介绍设备的排列方式，鼓风机的演示会介绍批量加工。完整页面会提供直接打开演示的按钮；这一版内容草稿尚未实现这些操作。

原料输送和产物收集属于仓储与物流。这里会链接到相应页面，不会重复解释整套运输系统。
