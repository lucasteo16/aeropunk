# Astropunk player-intent guide taxonomy

## Scope and status

This is the full proposed page register, not a finished handbook or an assertion that every useful function has been discovered. It replaces the earlier first-page shortlist for planning purposes while preserving both source documents. Every selected metadata path has one primary function. Secondary memberships are related-page links and do not add to installation totals. Pages are grouped by player interest and remain independent. No quests, content locks, rewards or mandatory reading order are planned. Ordinary survival requirements remain separate gameplay rules.

Plan the complete register first, then tune one approved vertical slice for presentation and evidence quality. Only after that review should authors batch the remaining pages. The register below includes those later pages now, including deferred and provisional scope. No presentation dependency is selected by this document.

The home screen uses eight broad player-intent cards, not the previous flat list of technical areas. At most two category levels are allowed: a home goal and its subordinate topic. The next selection opens article content, never another navigation folder. Its technical reference separates libraries and compatibility from optimization, server tools, and visible appearance choices. Category order is not progression. Deferred space pages are open planning references clearly marked absent from the baseline; they must not advertise working baseline planetary travel.

## Locale and page contract

Every proposed page targets English `en_us` and Simplified Chinese `zh_cn` only. No additional locale is planned. Page identifiers and metadata paths are stable literal identifiers. Project names may remain literal when needed for search. No translated body or search index is verified. Search may remain English only if an approved interface check confirms that item names, query behavior and guide article discovery work reliably. English-only search is not yet verified. Before publication, check Chinese glyph rendering, search aliases, item names, image captions, link labels and visible fallback for untranslated content.

Each page needs an illustrated activity, a brief comparison of relevant systems, a verified useful action, an exact item-browser search where applicable, existing-help links and optional related pages. Libraries and terrain may have no item-browser results. A missing result does not prove absence. Screenshots and scenes are planned assets, not completed visuals. No addon receives an assumed Ponder scene or invented documentation book.

Every page below has locale scope `en_us` and `zh_cn` only. Existing help is upstream or previously documented unless specifically marked unconfirmed. All instruction checks remain pending; a static coverage pass is not gameplay certification.
