# First writing batch

## Structure settled

Quick reference and Mod catalogs share one topic tree. The same reference pages are reachable from the homepage and the left navigation. Reference content answers what exists, where it occurs and how to access it. Getting started is a short section within that topic, with a companion article only when substantial. There is no separate tutorial tree and no mandatory paired page for each topic.

The structural pass adds six real directories for grouped topics, ordered reference navigation, area-specific mod headings, compact decorative homepage icons, clear separators, and updated authoring templates. Unwritten content retains its completion marker. Directory creation must not inflate counts of completed content articles.

Verify selected artifacts, configuration and overrides before asserting availability. Do not turn model resources, templates or unused spawn eggs into an invented content total.

## Style for each section

Lead with authentic identification visuals and a concise comparable content table. Show name, introducing mod, location and access in consistent fields. Expand only where a feature needs explanation. Keep all body content beneath second-level headings and avoid redundant introduction prose or repeated provider slogans.

Add Getting started only where it helps a player begin: finding an appropriate location, obtaining the first relevant item, or opening the existing interface or demonstration. Do not force a crafting lesson into a creature or terrain catalog. Maintain English and Simplified Chinese together, with source evidence kept in repository notes rather than intrusive player-facing implementation prose.
