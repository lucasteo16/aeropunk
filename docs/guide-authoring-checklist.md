# Guide authoring checklist

## Design contract

Keep the categories in guide-navigation-revision.md. Every selected mod must be named in at least one discoverable guide or reference entry. Cross-links may repeat a mod, but this checklist owns one tracking row per selected metadata path. Libraries receive brief searchable reference entries, not invisible omissions. Deferred content is clearly marked absent from the baseline.

The homepage uses existing Minecraft item icons arranged as an activity map, with readable category labels. Start with a static icon layout, not an assumed draggable graph. Balance information density with clear click targets. Use image generation sparingly for assets that existing icons cannot supply.

English and Simplified Chinese only. Use concise explanatory paragraphs for engine research, nested lists for category structures.

## Milestones

- [x] Inventory every baseline mod and visual pack.
- [x] Assign every entry to the revised category structure.
- [ ] Reconcile the older detailed taxonomy and page register with these assignments.
- [ ] Review integration findings and notify Lucas about actionable concerns.
- [ ] Finalize item-icon homepage layout and category labels.
- [ ] Implement one approved representative section and its client actions.
- [ ] Verify English search under both game languages.
- [ ] Tune the section with Lucas before batch authoring.
- [ ] Write and translate the remaining pages in batches.
- [ ] Check every selected mod has a visible mention and working index link.

## Coverage

Indexed means assigned for tracking, not finished or tested. Every unchecked entry below still needs a player-facing mention. The structured companion tracks instruction verification, both languages and links independently.
