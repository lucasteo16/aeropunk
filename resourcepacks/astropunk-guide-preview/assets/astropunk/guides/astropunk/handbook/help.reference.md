# Existing help

## Read advancements

Open the Advancements screen to browse discovered goals and their conditions. Reliable Advancements improves this screen, it is not a separate quest book or a compulsory order for playing the pack.

Use an advancement as a clue about its associated activity. For equipment choices, class abilities and machine assembly, use the relevant handbook topic instead of assuming the advancement supplies a complete tutorial.

***

## Editing is optional

The mod also provides advancement editing features. Editing support and permissions are separate from ordinary progression, do not use an editor as a required survival step.
