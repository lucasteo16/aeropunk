# 了解暂缓加入的优化模组

## 暂缓加入

这些优化候选已暂缓加入，不属于轻型版或重型版。

| 内容 | 作用 |
| --- | --- |
| Async Logger（暂缓） | 异步日志处理。 |
| Jasione（暂缓） | 减少重复的枚举数组分配。 |
| ServerCore（暂缓） | 服务器优化。 |
