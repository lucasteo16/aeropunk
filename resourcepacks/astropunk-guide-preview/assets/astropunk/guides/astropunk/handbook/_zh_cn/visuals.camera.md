# 调整视角与窗口

## 镜头与窗口

缩放、独立观察与无边框全屏分别满足不同观察需求。自由镜头改变视点，不改变玩家位置。多人游戏规则可能限制镜头工具。

| 内容 | 作用 |
| --- | --- |
| Cubes Without Borders | 提供无边框全屏窗口。 |
| Freecam | 提供独立观察镜头。 |
| Ok Zoomer - It's Zoom! | 提供可调整的镜头缩放。 |
