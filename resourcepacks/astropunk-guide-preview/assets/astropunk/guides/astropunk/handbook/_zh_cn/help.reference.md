# 进度

## 查看进度

Better Advancements 改善进度界面。打开界面可浏览目标与条件，Minecraft 与内容模组的进度保持不变。这不是独立任务书，整合包也没有强制阅读或完成顺序。

进度可作为对应玩法的线索。装备选择、职业能力与机器组装应查看手册主题或模组自带帮助，不要把进度说明当作完整教程。
