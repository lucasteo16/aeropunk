# 吟游诗人

![YouTube](images/tutorial-video.png) [English](https://www.youtube.com/results?search_query=Minecraft+1.21.1+Bards+RPG+Bard+abilities+equipment+tutorial+English) · [中文](https://www.youtube.com/results?search_query=%E6%88%91%E7%9A%84%E4%B8%96%E7%95%8C+1.21.1+Bards+RPG+%E5%90%9F%E6%B8%B8%E8%AF%97%E4%BA%BA+%E6%8A%80%E8%83%BD+%E8%A3%85%E5%A4%87+%E6%95%99%E7%A8%8B+%E4%B8%AD%E6%96%87)

## 定位与入门武器

吟游诗人使用鲁特琴与里拉琴进行奥术攻击与辅助，也以刺剑与竖琴弩作为其他武器选择。

![战斗中的吟游诗人](images/visual-bard-music.png)

### 值得关注的内容

吟游诗人的乐器同时提供奥术强度与治疗强度，因此一件手持乐器可以兼顾伤害歌曲与辅助歌曲。木鲁特琴的配方是白桦木板、线与木棍，是最便宜的起步方式。官方维护文档把鲁特琴描述为两种学派之间的平衡选择，把里拉琴描述为偏治疗的乐器，具体数值以你手持乐器的物品提示为准。

歌曲绑定在乐器上，而不是绑定在职业上。本页说明每件具名乐器可以带有不同的歌曲，因此第二把鲁特琴带来的是另一首歌，而不是第一首的复制品。交易或制作之前，先读提示里的歌曲行。

艺人华服用皮革、羊毛与紫色染料，早期就能做，不必进入下界。游吟诗人华服用兔子皮、羊毛与金锭，下界合金游吟诗人华服是它的锻造升级。说书人华服是更晚的套装，依赖其他装备。华服部件用物理防护换取法术强度与移动速度，因此预计会被打到的诗人要提前考虑这一点。

刺剑与竖琴弩是物理选项。铁刺剑用铁与皮革，竖琴弩用绊线钩、木棍与线。它们不消耗符文，因此在歌曲的符文不足时是有用的替代手段。

一次成功的初次使用是这样的。手持木鲁特琴，对敌对生物演奏它的歌曲，看到效果命中、符文减少，再在盟友附近演奏辅助歌曲并确认增益出现。如果歌曲毫无反应，先确认乐器在主手，并确认歌曲所需的符文在符文袋里。

### 准备阶段

这些检查点是可选的。任何阶段都可以正常游玩，玩家也可以停在当前阶段。

| 阶段 | 就绪条件 | 下一步选择 |
| --- | --- | --- |
| 前期 | 有白桦木板、线与木棍做木鲁特琴，有皮革、羊毛与紫色染料做一件华服。 | 演奏一首歌曲，并用刺剑或鲁特琴挥击打一个怪物。 |
| 中期起步 | 能走到周围有书架的法术绑定台，并付得起费用。 | 绑定吟游诗人职业书，手持乐器或武器时装备它。 |
| 中期 | 能取得金锭与线，并收集兔子皮。 | 比较金里拉琴与木鲁特琴，以及游吟诗人华服与艺人华服。 |
| 后期 | 持有下界合金升级锻造模板与下界合金锭，或得到一件独特乐器。 | 每次升级一件游吟诗人华服部件，替换在用乐器前先读独特乐器的歌曲行。 |
