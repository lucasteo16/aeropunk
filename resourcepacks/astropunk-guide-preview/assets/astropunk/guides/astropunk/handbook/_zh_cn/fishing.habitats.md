使用 Starcatcher 图鉴查看鱼种的完整条件。下表说明从哪里开始寻找，并不保证每个水池都有全部所列渔获。

| 栖息地 | 渔获与地形示例 |
| --- | --- |
| 寒冷淡水 | Frostjaw Trout 与 Wintery Pike。寒冷和冰冻的 Terralith 地形包括 Birch Taiga、Windswept Spires 与冬季岛屿。 |
| 温暖淡水 | Sandtail、Scorchfish、Mirage Carp、Agave Bream、Cactifish 与 Oasis Sturgeon。干旱、沙漠、恶地和热带草原地形包括 Granite Cliffs。Snowy Badlands 不提供这些温暖渔获。 |
| 樱花地形 | Blossomfish 与 Pink Koi。Sakura Grove、Sakura Valley、Snowy Cherry Grove 与 Spring Skylands 共用樱花栖息地渔获。 |
| 繁花地形 | Petal Bass。花卉山谷、春季空岛与 Terralith 繁花森林分类，包括 Cloud Forest 与 Moonlight 地形。 |
| 开阔草地 | Sunflower Carp。草原及类似的开阔草地。 |
| 黑森林 | 魔法森林渔获也扩展到 Moonlight 林地。 |
| 冰雪地形 | Aurora 与其他冰刺渔获。冰冻峭壁、Glacial Chasm 与 Emerald Peaks。 |
| 繁茂洞穴 | Lush Pike、Mossfin 与 Shadowfin。真菌洞穴与 Underground Jungle 也属于此栖息地。 |
| 岩石洞穴 | Dripfin 与 Fossilized Angelfish。石质洞穴与地热洞穴共用滴水石渔获。 |
| 深暗之域 | Sculkfish、Ward 与 Glowing Dark。Frostfire Caves 也有匹配的幽匿地形。 |
| 海洋 | 海洋、深海与暖水海洋渔获包括 Terralith 的 Deep Warm Ocean。Hybrid Aquatic 兼容组件保留各海鱼自己的条件。 |

## Terralith 钓鱼

整合包为全部九十五种 Terralith 生物群系接入适合的地表或地下水域渔获。部分地形保留一般淡水、森林、丛林或针叶林鱼类，并非每种地形都有独有鱼种。生物群系符合条件，也不保证你所在的具体位置天然有水。

Frostfire Caves 同时提供幽匿与滴水石渔获。普通深层、虫蚀和地幔洞穴保留地下淡水渔获。稀疏竹子不等同于密集竹林，下界与末地也保留原有维度限制。

## 查看垂钓条件

| 条件 | 检查内容 |
| --- | --- |
| 生物群系 | 在图鉴中悬停查看多个栖息地选项。范围较广的栖息地标签可包含原版群系以外的地形。 |
| 高度与光照 | 同一生物群系内，地表、洞穴与高山渔获可能不同。检查钓点的高度与光照。 |
| 时间与天气 | 选择合适生物群系后，白天、夜晚、雨天与雷暴限制仍然适用。 |
| 流体与维度 | 水、熔岩与其他垂钓介质不同。主世界水域不能代替下界熔岩。 |
| 鱼饵 | 区分偏好的鱼饵与必需的鱼饵。 |

栖息地整合改变钓鱼竿的渔获资格，不扩展自然动物生成标签，也不增加野生生物密度。渔获稀有度、小游戏难度与其他条件仍取决于各鱼种。
