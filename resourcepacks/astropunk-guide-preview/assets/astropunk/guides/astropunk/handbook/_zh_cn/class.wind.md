# 风系法师

![YouTube](images/tutorial-video.png) [English](https://www.youtube.com/results?search_query=Minecraft+1.21.1+Elemental+Wizards+RPG+Wind+Wizard+abilities+equipment+tutorial+English) · [中文](https://www.youtube.com/results?search_query=%E6%88%91%E7%9A%84%E4%B8%96%E7%95%8C+1.21.1+Elemental+Wizards+RPG+%E9%A3%8E%E7%B3%BB%E6%B3%95%E5%B8%88+%E6%8A%80%E8%83%BD+%E8%A3%85%E5%A4%87+%E6%95%99%E7%A8%8B+%E4%B8%AD%E6%96%87)

## 定位与入门武器

风系法师使用风魔杖与法杖，招式包含瞄准攻击、持续范围与自身效果。

![元素法师长袍](images/visual-elemental-robes.png)

### 值得关注的内容

风系法术按风强度计算。羽毛魔杖提供风强度，配方只要羽毛与木棍，遇到第一批鸡之后就能做出。绑定职业书之前，先读清学派词条。

风魔杖与风法杖是专精升级。风魔杖需要幻翼膜，意味着露天过夜或交易，法杖延续这条线。元素法杖同时提供风、土与水强度，但需要下界之星，因此属于后期目标。

风之长袍用风弹与羊毛支撑本学派，胸甲额外需要金锭。飓风长袍是更晚的升级，配方使用史诗护甲升级与监守者升级水晶。元素长袍覆盖三种元素学派。

风系招式用来改变位置与占住空间。旋风与龙卷是留在场上的范围，上升气流与风场需要目标。先把敌人推开再往地面放范围的构筑，符文要备足两种施放。

一次成功的初次使用是这样的。手持羽毛魔杖，对追着你的敌对生物施放，看它被推开或停住，再在它所在的位置施放旋风。如果目标完全不移动，先确认用的是瞄准法术而不是地面法术。

### 准备阶段

下面阶段都是可选的。它们描述能接触到什么、能做到什么，不是必经顺序。

| 阶段 | 就绪条件 | 下一步选择 |
| --- | --- | --- |
| 前期 | 有羽毛、木棍，以及魔杖法术指定的符文。 | 做出羽毛魔杖，对一个敌对生物施放一次。 |
| 中期起步 | 能走到周围有书架的法术绑定台，并付得起费用。 | 绑定风系职业书，手持兼容法器时装备它。 |
| 中期 | 能取得风弹与幻翼膜。 | 比较风之长袍与风法杖。如果通用长袍的加成更贴合你的施放，就继续用它。 |
| 后期 | 能获得一次史诗护甲升级或下界之星。 | 一次只选一个目标，替换在用部件之前先确认新部件的学派加成。 |
