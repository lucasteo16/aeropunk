# 调整模型与动画

## 模型支持

Entity Model Features 与 Entity Texture Features 提供自定义模型与纹理支持。Model Gap Fix 修复可见模型缝隙。自定义动画外观也取决于已启用资源包。

| 内容 | 作用 |
| --- | --- |
| [EMF] Entity Model Features | 加载兼容资源包中的自定义实体模型。 |
| [ETF] Entity Texture Features | 支持随机、自定义与发光实体纹理。 |
| Model Gap Fix | 修复方块与物品模型的缝隙。 |

***

## 动画兼容

EMF Compat: Create 使机械动力动画适配动态玩家模型，其共享框架列在支持库页面。

| 内容 | 作用 |
| --- | --- |
| EMF Compat: Create | 使机械动力玩家动画适配自定义动态模型。 |

***

## 其他版本内容

以下动画扩展未安装在此版本中。未安装不代表已安装功能尚未完成。

| 内容 | 作用 |
| --- | --- |
| Eating Animations（未安装） | 增加进食动画。 |
| Fancy World Animations [FWA]（未安装） | 为门、拉杆等可交互方块增加动画。 |
| EMF Compat: Not Enough Animations（未安装） | 使 Not Enough Animations 适配自定义动态玩家模型。 |
| Not Enough Animations（未安装） | 在第三人称显示更多玩家动作。 |
| Spawn Animations Compats（未安装） | 为 Spawn Animations 补充兼容数据。 |
| Spawn Animations（未安装） | 为敌对生物生成增加动画。 |
