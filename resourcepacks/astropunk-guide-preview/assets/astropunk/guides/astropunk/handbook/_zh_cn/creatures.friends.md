# 友好与敌对生物

## Friends&Foes

![招手的螃蟹](images/encounters-friends-and-foes-forge-waving-crab.png)

招手的螃蟹

| 生物 | 遭遇地点与特点 |
| --- | --- |
| 铜傀儡 | 用铜块、避雷针和雕刻南瓜建造。 |
| 凝灰岩傀儡 | 用凝灰岩、羊毛和雕刻南瓜建造，也可在要塞发现。 |
| 螃蟹 | 主世界红树林沼泽与沙滩，用海带繁殖。 |
| 怒目怪 | 主世界繁茂洞穴。 |
| 冰术师 | 主世界积雪生物群系与冰术师小屋。 |
| 幻术师 | 主世界针叶林的幻术师小屋与训练场。 |
| 哞花 | 主世界繁花森林、樱花林、草甸与向日葵平原。 |
| 淘气鬼 | 主世界废弃矿井，完成捉迷藏可获得奖励。 |
| 大胃怪 | 主世界沙漠、恶地与热带草原变种。 |
