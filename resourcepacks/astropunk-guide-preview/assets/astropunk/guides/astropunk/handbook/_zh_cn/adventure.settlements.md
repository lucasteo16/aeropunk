# 探索聚落与法术图书馆

## Tidal Towns

![Tidal Towns 海上村庄](images/visual-ocean-village.png)

Tidal Towns 海上村庄

![Tidal Towns](images/catalog-eeiwvqvo.png)

Tidal Towns 在主世界的深海生物群系加入海上村庄。生成范围不包括所有深海变种，也不会仅因名字相似就包含所有 Terralith 海洋。应在新生成地形寻找，而非已经探索过的海岸。

| 建筑类型 | 变体 |
| --- | --- |
| 村庄中心 | 中央村庄平台。 |
| 农场 | 小型农场与大型农场。 |
| 工作场所 | 武器匠建筑。 |
| 塔楼 | 塔楼一与塔楼二。 |
| 房屋 | 小型房屋，配有连接道路与村庄末端部件。 |

这些是拼装村庄的建筑部件，并非六种独立村庄。出发时带上船。

- [船只与潜艇](vehicles.water.md)
- [钓鱼](food.fishing.md)

## 村庄

![Alpine-style mountain village](images/encounters-ct-overhaul-village-catalog.png)

阿尔卑斯风格山村。

ChoiceTheorem's Overhauled Village

下列村庄风格均有小型、中型和大型变体。除蘑菇岛外，表中的名称均为 Terralith 生物群系。列出相同生成地点的风格合并展示，部分行只列举符合条件的生物群系示例，并非完整生成标签。

| 风格 | 生物群系 |
| --- | --- |
| Beach | Gravel Beach |
| Christmas, Snowy Igloo | Alpine Grove、Cold Shrubland、Emerald Peaks、Rocky Shrubland、Scarlet Mountains等匹配生物群系 |
| Desert, Desert Oasis | Desert Oasis、Desert Spires、Lush Desert、Sandstone Valley |
| Dark Forest | Sakura Grove、Sakura Valley |
| Jungle, Jungle Tree | Amethyst Canyon、Amethyst Rainforest、Jungle Mountains、Rocky Jungle、Tropical Jungle |
| Mesa, Mesa Fortified | Bryce Canyon、Painted Mountains、Red Oasis、Savanna Badlands、Snowy Badlands、White Mesa |
| Mountain, Mountain Alpine | Alpine Grove、Ashen Savanna、Caldera、Emerald Peaks、Painted Mountains等匹配生物群系 |
| Mushroom | 蘑菇岛 |
| Plains, Plains Fortified | Alpine Highlands、Arid Highlands、Blooming Plateau、Brushland、Highlands、Steppe、Temperate Highlands |
| Savanna, Savanna Na | Arid Highlands、Ashen Savanna、Fractured Savanna、Savanna Badlands、Savanna Slopes |
| Swamp, Swamp Fortified | Ice Marsh、Orchid Swamp |
| Taiga, Taiga Fortified | Alpine Grove、Birch Taiga、Forested Highlands、Shield、Siberian Grove等匹配生物群系 |
