# 调整通知与信息界面

## 视频选项

Reese's Sodium Options 重新组织视频菜单。Sodium Extra 增加外观、粒子、动画与信息显示控制。两者都不是地形渲染器本身。

| 内容 | 作用 |
| --- | --- |
| Reese's Sodium Options | 重新组织 Sodium 视频选项。 |
| Sodium Extra | 增加外观、粒子、动画与信息显示控制。 |

***

## 信息与通知

这些组件改变信息显示与通知，不改变玩法进度。隐藏实验性警告不会让世界内容变成非实验性。

| 内容 | 作用 |
| --- | --- |
| Advancement Plaques | 将进度通知替换为牌匾样式。 |
| Better ModList | 调整模组列表显示与筛选。 |
| BetterF3 | 重新组织调试信息显示。 |
| Hide Experimental Warning | 隐藏实验性世界警告。 |
| Progress Peek | 在桌面任务栏显示加载进度。 |
| Toast Control | 控制弹出通知。 |
| Traveler's Titles | 显示进入生物群系与维度的标题。 |
