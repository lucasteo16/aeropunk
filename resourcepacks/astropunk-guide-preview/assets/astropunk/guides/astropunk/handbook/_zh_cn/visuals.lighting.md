# 选择光影、动态光源与远景

## 概览

<ItemGrid>
  <ItemIcon id="minecraft:lantern" />
  <ItemIcon id="minecraft:spyglass" />
</ItemGrid>

| 功能 | 安装状态 |
| --- | --- |
| Iris 光影包 | 已安装；在光影设置中选择一个 |
| Distant Horizons | 已安装；默认关闭，可以自行开启 |
| Sodium Dynamic Lights 与移动建筑光源扩展 | 仅重型版；当前未安装 |

一次修改一个设置，在同一地点比较。目录见[光影风格](visuals.shader-packs.md)和[资源包](visuals.resource-packs.md)。

## 相关模组

| 模组或内容 | 官方简介 |
| --- | --- |
| Distant Horizons | Massively increase render distance without harming performance. |
| Iris Shaders | A modern shader pack loader for Minecraft intended to be compatible with existing OptiFine shader packs |
| Reese's Sodium Options | Alternative Options Menu for Sodium |
| Sodium Dynamic Lights（重型版，当前未安装） | 当前未安装。 |
| Sodium Extra | A Sodium addon that adds features that shouldn't be in Sodium. |
