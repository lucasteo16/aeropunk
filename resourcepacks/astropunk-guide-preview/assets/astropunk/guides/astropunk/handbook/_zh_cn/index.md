# Astropunk

## 属于你的世界

Astropunk 将机械自动化、自由建筑、探索与灵活的战斗培养结合在同一个生存世界中。

围绕 Create 机器建立工坊，用装饰材料和家具布置家园，或建造连接聚落的交通设施。在重新塑造的主世界、下界与末地寻找村庄、地牢、特殊生物和首领遭遇。

战斗风格由武器、护甲、饰品、职业书和技能树选择组成。按自己的计划选择系统，不必遵循强制任务路线。手册没有完成奖励或阅读锁，但具体制作、能力和目的地仍有各自的玩法条件。

***

## 下一个计划

从小目标开始：为探险准备食物与储存，制作实用机器，尝试建筑配色，或准备一种战斗风格的入门装备。配方浏览和 Create 的思索演示可以把构想连接到实际原料与组装方式。

需要查询具体主题时，直接在侧栏选择。主题页面会区分已安装内容与未安装的其他版本选项。
