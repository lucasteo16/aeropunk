# 寻找其他工厂工具

## 省下跑回家的路的工具

<EmiSearch query="@create_sa" /> <EmiSearch query="@create" />

Create Stuff 'N Additions 加入的手持工具靠物品内部储存的旋转工作，而不是靠工作站。小基地不必到处拉轴，原因就在这里。

<ItemGrid><ItemIcon id="create_sa:portable_drill" /><ItemIcon id="create_sa:copper_magnet" /><ItemIcon id="create_sa:block_picker" /><ItemIcon id="create_sa:grapplin_whisk" /></ItemGrid>

| 工具 | 替代什么 |
| --- | --- |
| <ItemLink id="create_sa:portable_drill" /> | 镐，并以机器速度破坏方块 |
| <ItemLink id="create_sa:copper_magnet" /> | 走过去捡掉落，它把掉落吸过来 |
| <ItemLink id="create_sa:block_picker" /> | 随身带着方块去连续放置 |
| <ItemLink id="create_sa:grapplin_whisk" /> | 攀爬，把你拉向表面 |

每件工具自带电量，从储罐补充。本包给装置 1600 点容量，一次加满够用一个工作时段，而不是整个工程。

## 储罐与便携引擎

<ItemGrid><ItemIcon id="create_sa:small_filling_tank" /><ItemIcon id="create_sa:medium_filling_tank" /><ItemIcon id="create_sa:large_filling_tank" /><ItemIcon id="create_sa:steam_engine" /></ItemGrid>

| 物品 | 本包容量 |
| --- | --- |
| <ItemLink id="create_sa:small_filling_tank" /> | 800 |
| <ItemLink id="create_sa:medium_filling_tank" /> | 1600 |
| <ItemLink id="create_sa:large_filling_tank" /> | 3200 |
| <ItemLink id="create_sa:steam_engine" />、<ItemLink id="create_sa:hydraulic_engine" />、<ItemLink id="create_sa:heat_engine" /> | 便携蒸汽、液压与热能引擎 |

注液罐是工具与喷气背包的补给站。放一个、装满，把工具对着它按住使用。一只大罐能补满四只小罐当量的装置，才需要再管一次。

本模组的便携蒸汽引擎不是 Create 的已放置 <ItemLink id="create:steam_engine" />。它是给装置用的手持或安装部件，不向应力网络供能。

## 无人机

<ItemGrid><ItemIcon id="create_sa:brass_drone_item" /><ItemIcon id="create_sa:drone_controller" /><ItemIcon id="create_sa:fan_component" /><ItemIcon id="create_sa:vault_component" /></ItemGrid>

| 部件 | 作用 |
| --- | --- |
| <ItemLink id="create_sa:brass_drone_item" /> | 无人机本体，从物品放出 |
| <ItemLink id="create_sa:drone_controller" /> | 设定无人机飞到哪里、做什么 |
| <ItemLink id="create_sa:fan_component" /> | 推动物品或实体 |
| <ItemLink id="create_sa:vault_component" /> | 收纳无人机捡到的物品 |

本包为无人机开启了钻头、风扇、磁铁与储物模块。其中三件有独立物品，储物模块是让一趟收集飞行值得做的那个。

先用一架无人机、一个模块、一段短路线。完全不动的时候，通常是没电，或者飞出了控制器设定的范围。

***

## 本包增加的捷径

<ItemGrid><ItemIcon id="minecraft:phantom_membrane" /><ItemIcon id="minecraft:feather" /><ItemIcon id="minecraft:brown_mushroom" /><ItemIcon id="minecraft:red_mushroom" /><ItemIcon id="minecraft:brown_mushroom_block" /><ItemIcon id="minecraft:red_mushroom_block" /><ItemIcon id="minecraft:prismarine_shard" /><ItemIcon id="minecraft:blue_dye" /></ItemGrid>

| 捷径 | 输入 | 产出 |
| --- | --- | --- |
| 缠魂羽毛 | 一根羽毛 | 一片幻翼膜 |
| 压缩蘑菇 | 四个同种蘑菇 | 一个同色蘑菇方块 |
| 熔炼碎片 | 一个海晶碎片 | 一份蓝色染料 |

<Recipe id="stam1ocreatetweaks:blasting/blue_dye" />

羽毛配方省掉了等幻翼的时间，任何需要幻翼膜的东西都因此变便宜。蘑菇方块配方是储存收获的便宜办法。蓝色染料配方让海洋拾获直接变成染料，不必种花。

下一步是给这些工具所支持的机器供能。[旋转动力](machines.rotation.md)统一说明传动线。
