# 调整天气、粒子与过渡效果

## 传送过渡

GrandTeleport 改变传送时的镜头过渡，不会创建生存旅行目的地，也不会授予传送权限。

| 内容 | 作用 |
| --- | --- |
| GrandTeleport NeoForge | 为传送增加电影式镜头过渡。 |

***

## 粒子与爆炸

重型版增加爆炸、状态粒子与环境视觉效果。粒子优化组件与视觉效果生成组件分开列出。

| 内容 | 作用 |
| --- | --- |
| Explosive Enhancement: Reforged（仅重型版） | 改变爆炸动画效果。 |
| Particle Effects（仅重型版） | 为原版状态效果提供不同纹理的粒子。 |
| Particular ✨ Reforged（仅重型版） | 增加环境视觉效果。 |
| Ripple（仅重型版） | 让粒子对实体作出反应。 |
