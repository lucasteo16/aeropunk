# 圣骑士

![YouTube](images/tutorial-video.png) [English](https://www.youtube.com/results?search_query=Minecraft+1.21.1+Paladins+and+Priests+Paladin+abilities+equipment+tutorial+English) · [中文](https://www.youtube.com/results?search_query=%E6%88%91%E7%9A%84%E4%B8%96%E7%95%8C+1.21.1+Paladins+and+Priests+%E5%9C%A3%E9%AA%91%E5%A3%AB+%E6%8A%80%E8%83%BD+%E8%A3%85%E5%A4%87+%E6%95%99%E7%A8%8B+%E4%B8%AD%E6%96%87)

## 定位与入门武器

圣骑士把近战与治疗学派辅助结合起来，使用钉锤、巨锤、巨剑与盾牌。

![神圣保护效果](images/visual-holy-protection.png)

### 值得关注的内容

圣骑士起步时不需要法术书。铁钉锤是用铁锭与木棍做出的普通近战武器，官方介绍也说明任何近战武器都可以作为起点。职业法术来自圣骑士圣典，发行方说明它最适合巨锤与巨剑这类重型武器。

铁钉锤没有治疗强度加成，因此想治疗时要把圣光魔杖或侍僧魔杖留在手上。侍僧魔杖的配方是木棍与线，圣光魔杖需要金锭与铁锭，所以侍僧魔杖是尝试治疗施放成本最低的方式。确定之前先看物品提示里的治疗词条。

圣骑士护甲的配方使用铜与铁，因此早期就能凑齐。十字军护甲是更晚的套装，下界合金十字军护甲是它的锻造升级。副手盾牌支持防守打法，发行方也明确提到这种搭配。

符文用于圣典里的法术，不用于钉锤挥击。把准备施放的法术指定的符文带在身上，并把近战武器看作不需要弹药的独立伤害来源。

一次成功的初次使用是这样的。用铁钉锤打中敌对生物并确认近战伤害正常，在法术绑定台绑定圣典，装备它并继续手持同一把钉锤，然后对自己或盟友施放快速治疗，看生命值回复。如果钉锤正常而治疗失败，问题出在符文供应而不是武器。

### 准备阶段

这些检查点是可选的。这里没有任何一项是游玩该职业的前提。

| 阶段 | 就绪条件 | 下一步选择 |
| --- | --- | --- |
| 前期 | 有铁锭与木棍做铁钉锤，有铜与铁做一件圣骑士护甲。 | 先用钉锤作战。材料到位时逐件补上圣骑士护甲。 |
| 中期起步 | 能走到周围有书架的法术绑定台，并付得起费用。 | 绑定圣骑士圣典。打算治疗时保留圣光魔杖或侍僧魔杖。 |
| 中期 | 能比较钉锤、巨锤与巨剑三条线，并有盾牌可用。 | 选择贴合你攻击距离与速度的武器专精，再判断副手是否值得放盾。 |
| 后期 | 持有下界合金升级锻造模板与下界合金锭。 | 逐件升级十字军护甲，并保留实际用来施法的治疗法器。 |
