# 火焰法师

## 定位与入门武器

<ItemGrid>
  <ItemIcon id="wizards:wand_novice" />
</ItemGrid>

<ItemLink id="wizards:wand_novice" />

<Recipe id="wizards:wand_novice" />

火焰魔法包含近距离范围、投射物与落下攻击。

| 能力 | 形式 |
| --- | --- |
| 烈焰吐息 | 范围 |
| 火焰斩 | 投射物 |
| 陨石术 | 落下攻击 |
| 火焰风暴 | 范围 |
| 火墙术 | 持续范围 |
| 火焰九头蛇 | 自身效果 |

新手法杖提供火焰强度，不是奥秘或冰霜法器。

***

## 职业法术书

<EmiSearch query="@spell_engine" />

<ItemLink id="spell_engine:spell_book" />

在法术绑定台放入普通书，选择火焰法师法术书。它是带有职业配置的法术书，并非独立物品类型。支付界面显示的经验等级，再用青金石和所需书架能量绑定上表招式。将书装备在支持的槽位，手持兼容武器或法器。

- [法术绑定与资源](combat.magic.md) 费用、武器兼容、符文与施法操作。
- [初次使用招式](combat.abilities.md) 绑定步骤，以及书籍招式与武器招式的区别。
