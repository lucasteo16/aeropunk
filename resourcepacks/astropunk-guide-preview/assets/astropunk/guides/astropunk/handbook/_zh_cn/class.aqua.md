# 水系法师

![YouTube](images/tutorial-video.png) [English](https://www.youtube.com/results?search_query=Minecraft+1.21.1+Elemental+Wizards+RPG+Aqua+Wizard+abilities+equipment+tutorial+English) · [中文](https://www.youtube.com/results?search_query=%E6%88%91%E7%9A%84%E4%B8%96%E7%95%8C+1.21.1+Elemental+Wizards+RPG+%E6%B0%B4%E7%B3%BB%E6%B3%95%E5%B8%88+%E6%8A%80%E8%83%BD+%E8%A3%85%E5%A4%87+%E6%95%99%E7%A8%8B+%E4%B8%AD%E6%96%87)

## 定位与入门武器

水系法师使用水魔杖与法杖，招式包含伤害法术与辅助范围。

![元素法师长袍](images/visual-elemental-robes.png)

### 值得关注的内容

水系法术按水强度计算。海带魔杖只提供水强度，配方只要海带与木棍，因此第一件法器需要一次海洋行程，而不是挖矿行程。绑定职业书之前，先读清学派词条。

水魔杖与水法杖是专精升级。元素法杖同时提供风、土与水强度，适合保留多本元素职业书的玩家，但配方需要下界之星，所以它是后期目标，不是起步法器。

海带长袍用海带、羊毛与海晶砂粒支撑本学派。海洋长袍是更晚的升级，配方使用史诗护甲升级与监守者升级水晶，因此依赖其他内容。元素长袍覆盖三种元素学派，是通用入门套装。

这个职业书本身带有辅助招式。清泉与治疗雨云都是范围效果，因此符文要同时留出治疗与伤害的用量。每条法术的提示都会写明消耗，没有符文消耗的法术不消耗任何符文。

一次成功的初次使用是这样的。手持海带魔杖，对敌对生物施放并确认水系法术命中，再在盟友之间施放清泉，看到范围效果出现。如果第二次施放失败，缺少的通常是治疗类符文，而不是魔杖。

### 准备阶段

以下都是可选建议，不是必经顺序，也不按游玩天数划分。

| 阶段 | 就绪条件 | 下一步选择 |
| --- | --- | --- |
| 前期 | 有海带、木棍，以及魔杖法术指定的符文。 | 做出海带魔杖并施放一次。材料允许时补上元素长袍部件。 |
| 中期起步 | 能使用周围有书架的法术绑定台，并付得起显示的费用。 | 绑定水系职业书，手持兼容法器时装备它。 |
| 中期 | 能取得海晶砂粒，并能比较水魔杖与水法杖。 | 按每件装备给出的学派加成，在海带长袍与水系长袍之间选择。 |
| 后期 | 能获得下界之星或一次史诗护甲升级。 | 把元素法杖与海洋长袍当作两个独立目标。两者互不要求。 |
