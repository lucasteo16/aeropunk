# Vehicles and travel

## Vehicle and Travel Mods

| Mod or content | Publisher description |
| --- | --- |
| [AeroEngine](vehicles.engines.md) | AeroEngine is a Create addon that adds modular aircraft engines and a pilot HUD for flight control and navigation. |
| [Create Aeronautics](vehicles.assembly.md) | Build anything from airships to planes and cars! |
| [Create Aeronautics: Encased Fluid Pipes](vehicles.airships.md) | Encase Create Fluid Pipes with the Create Aeronautics Hot Air Envelope |
| [Create Big Cannons](vehicles.weapons.md) | A Minecraft mod for building large cannons with the Create mod. |
| [Create Deep Seas](vehicles.water.md) | Submarine and boat in Create Aeronautics! |
| [Create Propulsion: Simulated](vehicles.engines.md) | Port of Create: Propulsion mod to NeoForge 1.21.1 with support of Sable and Create: Aeronautics |
| [Create Railways Navigator](transport.passenger.md) | A Minecraft Create Mod addon that adds several new features related to train navigation, such as improved display boards, a navigator for searching routes, new schedule entries, and more. |
| [Create Waystones Recipes](travel.destinations.md) | This mod changes the recipes of Waystones to fit with and use the Create mod. It also balances things a bit more. |
| [Create: Aeroworks](vehicles.controls.md) | A collection of addons for Create Aeronautics with blocks such as the gyroscope, joystick, and more! |
| [Create: Ballast](vehicles.airships.md) | Adds a new layerable block that has more mass with each added layer. Useful for balancing your aeronautics builds! |
| [Create: Blocks & Bogies](transport.railway-builder.md) | Adds larger train bogies with (and without) valve gear, and more |
| [Create: Escalated](transport.local.md) | A mod to add functional, aesthetic, and rotation-powered escalators to Create. |
| [Create: Hypertubes](transport.local.md) | Travel arround the world with tubes! |
| [Create: Radars](vehicles.radar.md) | Adding Radars (& more) to Create! |
| [Create: Tweaked Controllers](vehicles.controls.md) | An addon for the Create Minecraft mod that adds a way of controlling contraptions using an advanced controller |
| [NetherPortalFix](travel.destinations.md) | Ensures correct destinations when traveling back and forth through Nether Portals in Multiplayer. |
| [Steam 'n' Rails Neoforge](transport.railway-builder.md) | An unofficial port of Create: Steam 'n' Rails to 1.21.1. |
| [Tempad](travel.destinations.md) | Create a portal to anywhere from anywhere |
| [Waystones](travel.destinations.md) | Teleport from waystone to waystone or craft magical scrolls to warp. |
| [Waystones: Sable (Create Aeronautics Addon)](travel.moving-destinations.md) | A compatibility mod that allows Waystones to work properly within Sable's SubLevel system. Fixes teleportation, validation, distance calculation, and client synchronization for waystones placed inside or targeting SubLevels. |
