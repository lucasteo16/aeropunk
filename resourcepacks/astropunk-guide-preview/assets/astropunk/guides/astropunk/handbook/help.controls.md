# Controls and key bindings

## Change a binding

1. Open Options, then Controls, then Key Binds.
2. Use Controlling to search for an action or mod.
3. Select its binding and press the replacement key. Check conflicts before returning to play.

## Handbook access

Click Handbook in your inventory, or press F9 by default. Change Open Astropunk Handbook in Key Binds. Your current handbook key: <KeyBind id="key.astropunk_handbook_access.open" />.

## Item browser defaults

| Action while hovering an inventory item | Default |
| --- | --- |
| Recipes | R |
| Uses | U |

Change these inside the item browser settings. Create's Ponder prompt shows its own key.

## Readability

Open Video Settings and increase the interface scale for larger text. This also enlarges other interfaces. The handbook uses a bounded page width so paragraphs stay short.
