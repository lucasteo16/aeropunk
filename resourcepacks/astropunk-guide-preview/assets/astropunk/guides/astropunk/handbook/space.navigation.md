<ItemLink id="rocketnautics:hologram_block" />

<Recipe id="rocketnautics:hologram_block" />

Place the Hologram Table for an adjustable scale display of the universe. Short-click its configuration points to change the display scale. Use the display as an overview of the celestial system, not as a destination selector or automatic piloting control.

<ItemLink id="rocketnautics:sputnik" />

<Recipe id="rocketnautics:sputnik" />

The Sputnik Probe is a persistent chunk loader and reports biome colors. Its description mentions ComputerCraft cartography integration, but that integration is not a route control.

The base Cosmonautics planet records include the Overworld, Moon, Mars, gas giant and ice world. The separate Mars dimension comes from Create Cosmonautics Expansion. The off-world surfaces linked by these records are the Moon and Mars.

- [Space destinations](space.destinations.md) Identify the included landable worlds.
- [Orbital flight](space.vehicle-transfer.md) Read the physical ship transfer boundary.

## Helmet display

In Deep Space, <ItemLink id="rocketnautics:space_helmet" /> provides an orbital display. Toggle its alignment helper with <KeyBind id="key.rocketnautics.toggle_alignment" />. The mod default is Y. This changes the display, not the ship's steering.
